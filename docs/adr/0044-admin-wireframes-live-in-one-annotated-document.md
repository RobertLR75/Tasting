# Admin wireframes live in one annotated document

Wireframes for `Login`, `Arrangement`, `Breweries` og `Users` samles i ett dokument med én seksjon per skjermbilde, og hver seksjon annoterer domeneatferd som backend-feil, synlige handlinger og statusgating. Vi velger dette fordi én samlet referanse gjør det lettere for parallelle team å dele samme forståelse av flytene, uten at wireframene mister den operasjonelle presisjonen som kreves for implementasjon av admin-backoffice.
