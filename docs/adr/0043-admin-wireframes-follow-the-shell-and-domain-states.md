# Admin wireframes follow the shell and domain states

Wireframes for admin-frontendet lages som detaljerte low-fidelity skisser som følger det eksisterende backoffice-skallet med toppbar og venstremeny, mens login forblir en separat skjerm uten shell. Vi velger dette fordi wireframene da speiler faktisk navigasjon og sidehierarki i `Tasting.Admin`, samtidig som de tydelig viser hvilke handlinger, disabled states og statusoverganger domenet tillater per skjerm.
