# Admin page starts as a blank Blazor Web App in Aspire

Admin Frontend startes som en egen server-side Blazor Web App registrert i Aspire, med MudBlazor som UI-rammeverk og et bevisst tomt applikasjonsskall for videre utbygging. Vi velger dette fordi det gir en lav-friksjon start for et internt backoffice, holder hostingmodellen enkel, og lar oss etablere separat frontend-grense og navigasjonsstruktur før vi binder sidene til konkrete API-kontrakter og sidekrav.
