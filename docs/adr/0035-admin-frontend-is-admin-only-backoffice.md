# Admin frontend is an admin-only backoffice

Admin Frontend bygges som et rent backoffice for `Admin`-rollen og dekker administrasjon av katalog og arrangementer, ikke deltakerflyten for rating. Vi velger dette fordi domenet allerede skiller tydelig mellom adminansvar og participant-oppførsel, og en separat frontend for deltakeropplevelsen reduserer begrepsblanding, autorisasjonsstøy og risikoen for at administrative behov former rating-opplevelsen.
